# Guia do OptXbox (movido)

O guia de uso do OptXbox agora fica no repositório da ferramenta, em português e em inglês:

- Português (Brasil): [docs/pt-BR/FERRAMENTA.md](https://github.com/dfdx047/Optxbox/blob/main/docs/pt-BR/FERRAMENTA.md)

Para o Dragon Burst, a rodada de testes no PC é:

```
cd ~/Optxbox && python3 -m optxbox report --adb --adb-pattern "DragonBurst-logs-*.zip"
```

O formato dos logs e das capturas que o Dragon Burst escreve está em
[DIAGNOSTICO.md](https://github.com/dfdx047/Optxbox/blob/main/docs/pt-BR/DIAGNOSTICO.md) ·
[DIAGNOSTICS.md](https://github.com/dfdx047/Optxbox/blob/main/docs/en/DIAGNOSTICS.md).
